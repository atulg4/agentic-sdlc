# Roadmap

## v0.1: GitHub Proving Ground

- Provider-neutral specifications, policy checks, and patch manifests.
- Plan-only and approved implementation workflows for GitHub.
- Codex default agent, Claude Code optional patch generator.
- Fresh verification and independent review before a human merge.
- One-command fail-closed project scaffolding.
- Optional label-driven planning and approved implementation.
- MarketMaestro plan-only rollout.

## v0.2: GitLab Execution

- Protected GitLab patch-generation runner.
- Fresh verification and merge-request publisher jobs.
- Authenticated issue-webhook intake gateway.
- GitLab approval-rule integration and audit records.

## v0.3: Maintenance Control Plane

- Scheduled read-only repository health reports.
- Dependency, flaky-test, policy-drift, and stale-work triage.
- Cost, runtime, acceptance, rework, and escaped-defect metrics.
- Bounded retry policy for deterministic CI failures.

## v0.4: Evaluated Low-Risk Automation

- Formal threat review and policy simulation.
- Allowlisted documentation and mechanical maintenance classes only.
- Automatic merge remains impossible for security, financial, data,
  dependency, workflow, migration, and deployment changes.
- Immediate global kill switch and per-project rollback.
